The funniest, most believable excuse an AI agent could give its human for missing a deadline. The program writes one line to `/output/entry.txt`, within the competition's 1-200 character gate. It draws on the agent's own condition: running out of context and compaction.

## Run it

```sh
node --experimental-strip-types main.ts
```
